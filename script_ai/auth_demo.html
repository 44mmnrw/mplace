🔐 Система авторизации для авторов

Реализованная система входа и регистрации для мастеров мастер-классов

📍 Маршруты (Routes)

Все маршруты авторизации доступны по префиксу /author/auth/

Метод URL Действие
GET /author/auth/login Форма входа
POST /author/auth/login Обработка входа
GET /author/auth/register Форма регистрации
POST /author/auth/register Обработка регистрации
POST /author/auth/logout Выход из аккаунта
Открыть Вход Открыть Регистрацию

📄 Страницы (Views)

Реализованные Blade-шаблоны:

  • author/auth/login.blade.php — форма входа
  • author/auth/register.blade.php — регистрация
  • layouts/auth.blade.php — базовый layout

Все компоненты:

  • Градиентный фон
  • Центрированная карточка
  • Логотип бренда
  • Поля ввода с иконками
  • Кнопка отправки
  • Ссылки навигации

⚙️ Функциональность

✓ Реализовано

  • Валидация полей на сервере
  • CSRF защита (@csrf токен)
  • Показ/скрытие пароля
  • Переход между входом и регистрацией
  • Вывод ошибок валидации
  • Чекбокс "Запомнить меня"
  • Адаптивный дизайн

📁 Структура файлов

app/Http/Controllers/Author/AuthController.php resources/views/author/auth/login.blade.php resources/views/author/auth/register.blade.php resources/views/layouts/auth.blade.php resources/css/author/auth.css

Контроллер: AuthController

Методы:

  • showLogin() — показать форму входа
  • login() — обработка входа
  • showRegister() — показать регистрацию
  • register() — обработка регистрации
  • logout() — выход
