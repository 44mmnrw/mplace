# Система авторизации для авторов (мастеров)

## Описание

Реализованы страницы авторизации и регистрации для авторов мастер-классов согласно дизайну из Figma.

## Структура файлов

### Контроллер
- **`app/Http/Controllers/Author/AuthController.php`** — контроллер для обработки авторизации и регистрации

### Представления (Blade)
- **`resources/views/author/auth/login.blade.php`** — страница входа
- **`resources/views/author/auth/register.blade.php`** — страница регистрации
- **`resources/views/layouts/auth.blade.php`** — базовый layout для страниц авторизации

### Стили (CSS)
- **`resources/css/author/auth.css`** — стили для всех страниц авторизации

### Маршруты
Все маршруты группированы под префиксом `author/auth/`:

```
GET    /author/auth/login              → author.auth.login (форма входа)
POST   /author/auth/login              → author.auth.login.submit (обработка входа)
GET    /author/auth/register           → author.auth.register (форма регистрации)
POST   /author/auth/register           → author.auth.register.submit (обработка регистрации)
POST   /author/auth/logout             → author.auth.logout (выход)
```

## Дизайн

Реализованный дизайн соответствует макету в Figma:
- **Градиентный фон**: линейный градиент от светлого к голубому
- **Центрированная карточка**: белый фон с закругленными углами и тонкой границей
- **Логотип**: иконка в голубом квадрате с скругленными углами
- **Форма**: поля для ввода с иконками слева, кнопка входа/регистрации
- **Типография**: использован шрифт Arial (Onest в проекте)
- **Цветовая схема**: использованы CSS-переменные из `shared/variables.css`

## Компоненты формы

### Поля ввода (Form Input)
- **Email**: с иконкой конверта
- **Пароль**: с кнопкой для показа/скрытия пароля
- **Имя** (только на странице регистрации): с иконкой профиля

### Интерактивные элементы
- **Чекбокс "Запомнить меня"** (на странице входа)
- **Чекбокс согласия** (на странице регистрации)
- **Ссылка на переход между входом и регистрацией**
- **Ссылка на главную страницу**

### Валидация
Реализована валидация на стороне сервера с выводом сообщений об ошибках для каждого поля.

## Использованные CSS-переменные

```css
--primary-color: #5b95bd          /* Основной цвет кнопок и ссылок */
--primary-hover: #4a7a9d          /* Цвет при наведении */

--text-secondary: #6b7280         /* Вторичный текст */
--secondary-bg: #FFFFFF           /* Белый фон карточки */
--bg-input: #f0f4f7               /* Фон полей ввода */

```

## Тестирование

### Локальное тестирование

1. **Запуск сервера:**
   ```bash
   cd c:\laragon\www\mplace
   composer dev
   ```

2. **Открыть страницы:**
   - Вход: http://localhost:8000/author/auth/login
   - Регистрация: http://localhost:8000/author/auth/register

3. **Протестировать функциональность:**
   - ✓ Валидация полей (пустые поля, некорректный email)
   - ✓ Переключение видимости пароля (иконка глаза)
   - ✓ Переход между страницами входа и регистрации
   - ✓ Кнопка возврата на главную

### Проверка на мобильных размерах

Адаптивный дизайн протестирован для:
- **Desktop**: > 1024px (основной лэйаут)
- **Tablet**: 600px - 1024px
- **Mobile**: < 600px

## Использованные технологии

- **Blade**: Laravel шаблонизатор с @csrf токеном
- **CSS**: модульная архитектура с импортами
- **HTML5**: семантическая разметка
- **SVG**: иконки в виде инлайн-SVG для лучшей масштабируемости
- **Responsive Design**: мобильная адаптивность через @media queries

## Примечания

- Все пароли будут зашифрованы перед сохранением в БД
- Email должен быть уникальным в системе
- На странице регистрации требуется согласие с условиями использования
- Форма использует метод POST для безопасности
- Все поля обязательны (required)
